# CahyanaPool Website

Website profil dan portofolio CahyanaPool menggunakan React, Vite, JavaScript, dan CSS.

Lihat [DEPLOYMENT.md](./DEPLOYMENT.md) untuk menjalankan project, mengisi kontak resmi, membangun file produksi, dan menyiapkan backend Supabase.

```bash
npm install
npm run dev
npm run build
```

Foto portofolio diambil dari `public/images`. Logo menggunakan `/images/logokali.jpeg` dan hero menggunakan `/images/herosection.jpg`.
